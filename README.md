# 키움 모의투자 단타 자동매매 봇

거래량 급증 종목을 스크리닝하고 돌파 시그널이 나오면 진입하는 모멘텀 스캘핑 봇입니다. 하루 목표 수익 100만원 도달 또는 손실 한도 도달 시 자동으로 매매를 중단합니다.

## 중요 안내

일 100만원은 코드에 설정된 목표값일 뿐 보장되는 수익이 아닙니다. 실제 시장에서는 목표에 못 미치거나 손실이 날 수 있습니다. 반드시 모의투자로 충분히 검증한 뒤 실계좌 전환 여부를 판단하세요.

## 요구 환경

이 봇은 키움 Open API+(OCX 컨트롤)를 사용하므로 다음 환경에서만 실행됩니다.

- Windows OS
- 32비트 Python 3.8 이상
- 키움 Open API+ 모듈 설치 및 영웅문 로그인 계정
- 모의투자 서버 신청 완료 상태

리눅스나 macOS에서는 OCX 컨트롤을 로드할 수 없어 실행이 불가능합니다.

## 설치

```
pip install -r requirements.txt
```

## 실행

```
python main.py
```

실행하면 로그인 창이 뜨고 로그인 후 예수금 조회와 거래량 급증 종목 스크리닝을 진행한 뒤 실시간 감시를 시작합니다.

## 전략 개요

1. `opt10023`으로 전일 대비 거래량 급증 종목을 스크리닝
2. 후보 종목 실시간 체결가를 구독
3. 최근 20틱 고점 돌파 + 거래량 급증 조건 충족 시 매수
4. 매수가 대비 -2% 손절 또는 +3% 익절 도달 시 매도
5. 15시 이후 신규 진입 중단 15시 20분 이후 전량 강제 청산
6. 누적 실현손익이 목표 100만원 도달 또는 손실 한도 도달 시 당일 매매 중단

## 설정 값 변경

`config.py`에서 목표 수익 손절 익절 비율 동시 보유 종목 수 등을 조정할 수 있습니다.

## 테스트

리스크 관리와 전략 로직은 OCX 의존성 없이 단위 테스트로 검증할 수 있습니다.

```
pip install pytest
pytest tests/
```
